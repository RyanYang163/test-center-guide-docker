常见问题

部署与使用中最常被问到的几件事。

部署完 Test Center 之后，用什么账号登录？

默认管理员是 test / Admin123（部署工具创建，可在部署时改）；手动部署则是你在「部署指南」第 7 步传给 create_superuser 的用户名、邮箱与密码。两种情况都要在首次登录后立刻改密码 —— 它拥有整个平台的权限。

这个指南应用本身占用了哪个端口？

宿主机端口 19013，容器内监听 8080。端口可在应用安装后按需调整，但要保证容器映射同步改。

镜像是从哪来的？

镜像托管在 Docker Hub 的公共仓库里，基于官方 nginx 的 alpine 变体构建；站点页面为本项目自有内容，完整源码在仓库中可查。

应用有哪些数据目录？

只有访问日志：/Volume*/DockerAppData/test-center-guide-docker/logs。站点是纯静态内容，部署助手生成的数据只写在你浏览器本地，服务端不保存任何东西。

怎么升级？

TOS 的 Docker 应用不支持平台内升级，只能卸载后重装；卸载时不要勾选「同时删除数据」，DockerAppData 下的内容会保留。

Test Center 平台本身怎么部署？

去「部署指南」页，那里有从零开始的完整命令；也可以先用「部署助手」生成一份属于你环境的 .env。

权限与数据处理

项说明
运行用户容器内以 uid/gid 1000 的非 root 用户运行
网络访问仅监听容器内 8080，不发起任何对外请求
收集的数据无。不采集访问者信息，不写入第三方服务
本机存储仅在你浏览器里保存语言偏好（localStorage）；生成结果需要你手动下载才会落盘
服务端存储仅 nginx 访问日志，落在 DockerAppData 下的 logs 目录

卸载时数据去哪了

  • 默认卸载（不勾选删除数据）：/Volume*/DockerAppData/test-center-guide-docker/ 完整保留，重装后还在
  • 勾选删除数据的卸载：仅清理上面这个目录，容器与镜像一并移除
