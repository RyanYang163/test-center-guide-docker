功能总览

Test Center 把测试团队日常用到的工具收在一个平台里：用例与套件管理、接口测试、UI 自动化、APP 自动化、性能压测、需求分析、知识库检索与报表。

功能模块

模块能力
项目与版本项目、版本、模块树；测试资产统一归档在同一处
用例与套件用例编写、评审、步骤化执行、套件编排与批量执行
接口测试接口定义、接口用例、场景编排、自动化执行与断言

技术栈

层选型
前端Vue 3 + Vite，构建产物由 nginx 伺服
后端Django 4.2（ASGI），REST + WebSocket
异步任务Django-Q2 集群，处理定时与耗时任务
数据库MySQL 8（utf8mb4）
缓存 / 队列Redis 7
执行依赖Playwright + Chromium（UI）、JMeter + JRE（压测）、Tesseract（OCR）、ADB（真机）
可选组件Apache Tika（文档解析）、Qdrant（向量库）、InfluxDB（时序看板）

为什么后端镜像很大、首次启动很慢？

因为后端不只是「网页的后台」，它还要在容器里真正执行测试：开浏览器跑 UI 用例、跑 JMeter 压测、连真机做 APP 自动化、做 OCR 识别。Chromium、JMeter、Tesseract 这些执行依赖都装在它里面。

另外首次启动要按顺序跑完数十个子应用的数据库迁移，实测可达十几分钟 —— 这段时间属于一次性初始化，不是卡死。

运行形态

按需要选最小集或完整集，两种形态共用同一套镜像：

形态容器适用
最小运行集前端、后端、MySQL、Redis单人或小团队：用例、接口测试、基础报表
完整运行集最小集 + 任务消费者、Tika、Qdrant、InfluxDB需要文档解析、知识库检索、压测看板与定时任务

对外只需要暴露前端一个端口（默认 19613）：后端、数据库、缓存全部留在容器网络内部，由前端 nginx 反向代理，不额外开放端口。
