Test Center 上手指南

Test Center 是面向测试团队的一体化测试管理平台：用例管理、接口测试、UI 自动化、APP 自动化、性能压测、需求分析与知识库检索。本页把「怎么装起来、怎么用起来」整理成一份可离线查阅的指南，并提供在浏览器内直接生成配置的部署助手。

先从这里开始

01

功能总览

平台由哪些模块组成、各能解决什么问题、跑起来需要几个容器。

 02

部署指南

两种部署方式（一键脚本 / 手动分步）的完整命令与前置条件。

 03

部署助手

填几个参数，自动生成 .env 文件与整套部署命令，可复制可下载。

 04

常见问题

端口、镜像来源、数据目录，以及升级卸载时数据去哪了。

本应用是纯粹的使用指南：所有页面都在容器内的 nginx 上伺服，不连接任何外部服务、不收集任何数据。部署助手完全在你的浏览器里计算，生成的结果只保存在本机，不会上传。

需要先在 TOS 应用中心安装并启用 DockerEngine。

技术栈与运行形态

组件说明
前端Vue 3 单页应用，由 nginx 伺服并反向代理后端接口
后端Django（ASGI）+ Django-Q2 异步任务消费者
数据库MySQL 8（业务数据）
缓存 / 队列Redis 7
可选组件Apache Tika（文档解析）、Qdrant（向量检索）、InfluxDB（压测看板）
最小运行集前端 + 后端 + MySQL + Redis（4 个容器）
完整运行集再加 Tika / Qdrant / InfluxDB / 任务消费者（8 个容器）

完整栈首次安装耗时主要在数据库迁移（后端含数十个子应用的迁移脚本），实测可达十几分钟；只是体验界面的话，用最小运行集更快。
